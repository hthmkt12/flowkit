# FBKit Marketing Overview

Last updated: 2026-05-08

## Strategy Snapshot

FBKit is positioned as a safer local-first Facebook automation assistant for agencies and marketers. Core differentiation is local execution with safety-gated live actions, instead of always-on cloud automation.

| Item | Value |

| Market | Global, remote-first |
| Budget | Lean / bootstrap |
| Website | No public site yet |
| Pricing | TBD / not public |

## Messaging Priorities

1. **Safety first:** dry-run by default, controlled live actions.
2. **Local trust:** automation runs with local control rather than opaque cloud execution.
3. **Operational clarity:** account routing, queue state, and status visibility are built into product workflows.

## Channel Priorities

1. Product-led demos (primary).
2. Direct founder/agency outreach with demo clips and short walkthroughs.
3. Lightweight documentation-led lead capture until a public website is ready.
